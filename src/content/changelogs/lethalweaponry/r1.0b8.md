[ES]
## Nuevo HUD (HUD Editor)
- Herramienta visual (`GuiHUDEditor`) para posicionar elementos de la interfaz (ChainBlades, Blood Pact, Scythe, WarHammer). Reemplaza configuraciones estáticas.
- Permite previsualización con `SHIFT`, posee un panel lateral con *Snap to Grid* (10px) y botón de reinicio.

## Combate
- **Blood Pact (Katana):** Ahora atrae suavemente al objetivo con *Correa Elástica* en vez de atraerlo fijamente. Fallar un Fatality aplica cooldown regular en vez de aturdimiento; acertar otorga Dash e Invulnerabilidad temporal.
- **Hitscan Slash:** Barrido direccional dinámico y sin latencia implementado en Katana y Guadaña, corrigiendo errores de ángulo y desincronización de red.
- **WarHammer:** El Ground Slam requiere daño por caída real. Se aumentó la densidad de partículas del área de impacto.
- **Chain Blade:** Cooldown en mano secundaria para evitar spam. Fix de vista en primera persona.

## Configuración y UI
- Interfaz (`GuiConfigScreen`) rediseñada con subsecciones, barra de búsqueda mejorada, advertencias de reinicio `[*]` y corrección visual en los botones `R`.
- Rediseño estético y optimización de la Guía del mod (`GuiGuideScreen`), junto con reescritura de guías.
- Actualizador de Changelogs automatizado en segundo plano vía GitHub API.
- Descripciones de armas ocultas bajo `SHIFT` para limpiar los inventarios.
- Archivos `.lang` y descripciones reescritos de forma neutra y mecánica.

## Encantamientos
- **Devolution:** Reduce mecánicamente la defensa de parásitos (SRP Soft Dependency).
- **Hemofilia (Katana):** Daño de sangrado porcentual a la vida máxima.
- **Cosecha de Almas (Guadaña):** Genera orbes curativos al matar.
- **Ruptura (WarHammer):** Reduce temporalmente armadura/dureza con golpes críticos.
- **Dynamic Clamping:** Limita automáticamente el nivel de encantamientos si un administrador baja el nivel máximo en la configuración.
- Las estadísticas configuradas se inyectan dinámicamente en el nombre del encantamiento.

## Bug Fixes
- **BloodPact:** Corregido un congelamiento infinito del HUD y fallas de sincronización del cliente. Ahora los golpes directos y ataques de barrido incrementan la duración del pacto y aplican sangrado correctamente.
- **Scythe:** Medidor de esencia independiente (vía HUD Editor).
- Fix de panorama del menú principal al redimensionar.

[EN]
## New HUD System
- Visual editor (`GuiHUDEditor`) to freely drag and drop HUD elements. Replaces static numeric configurations.
- Features `SHIFT` preview, a sidebar with *Snap to Grid* (10px), and position reset functionality.

## Combat Mechanics
- **Blood Pact (Katana):** Now uses an *Elastic Leash* for gentle pulling instead of fixed attraction. Failing a Fatality applies a regular cooldown instead of Stun; succeeding grants a Dash and temporary I-frames.
- **Hitscan Slash:** Dynamic and network-delay-free directional hitscan for Katana and Scythe, fixing angle blind spots and server overhead.
- **WarHammer:** Ground Slam requires real simulated fall damage. Massively increased area particle density.
- **Chain Blade:** Off-hand cooldown added to prevent spam. 1st-person model fix.

## Configuration & UI
- Redesigned interface (`GuiConfigScreen`) with sub-sections, improved flat search, restart warnings `[*]`, and correctly updating `R` (reset) buttons.
- Complete visual overhaul and caching optimization for the in-game Guide (`GuiGuideScreen`) into a "Dark Grimoire" theme.
- Automated background Changelog updater via GitHub API.
- Weapon lore hidden behind `SHIFT` for cleaner tooltips.
- Standardized `.lang` files to pure mechanical descriptions.

## Enchantments
- **Devolution:** Mechanically strips parasite defenses (SRP Soft Dependency).
- **Hemophilia (Katana):** Max-health percentage bleed damage.
- **Soul Harvest (Scythe):** Generates healing orbs on kill.
- **Severance (WarHammer):** Temporarily reduces armor/toughness on crits.
- **Dynamic Clamping:** Automatically lowers item enchantment levels if the server admin decreases the config cap.
- Enchantment stats dynamically injected into the enchantment names.

## Bug Fixes
- **BloodPact:** Fixed infinite HUD freeze and client desyncs. Direct and slash attacks now properly increase pact duration and apply AoE bleeding.
- **Scythe:** Essence bar is now an independent HUD element.
- Fixed main menu panorama breaking upon resize.
[/EN]
