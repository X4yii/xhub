[ES]
LethalWeaponry es un mod para Minecraft Forge 1.12.2 que añade cuatro tipos de armas especializadas, cada una con mecánicas de combate, habilidades activas y una estación de forja exclusiva.

### 1. Lethal Forge (Forja Letal)

Las armas del mod no se fabrican en una mesa de trabajo estándar. Deben forjarse en la **Lethal Forge**.

**Crafteo de la Forja:**

![Crafteo de la Forja Letal](/img/lethalforge-crafting.png)

**Uso:**
La interfaz permite seleccionar el arma (WarHammer, Katana, Scythe, Chain Blade) y el material (Madera, Piedra, Hierro, Oro, Diamante). Requiere palos e hilos dependiendo del arma. Las recetas completas se pueden consultar mediante **Just Enough Items (JEI)**.

### 2. Interfaces (HUD & Configuración)

#### HUD Editor
El mod cuenta con indicadores en pantalla para los cooldowns de habilidades, pactos de sangre e indicadores de doble empuñadura.
Para reposicionar la interfaz, entra al mundo, presiona la tecla configurada o usa el menú Mod Options y accede al **HUD Editor**. Aquí puedes arrastrar, soltar y ajustar cada panel visual. Mantener **Shift** muestra todos los elementos ocultos temporalmente para facilitar su reubicación.

#### Menú de Configuración
Todo el comportamiento lógico del servidor y las preferencias del cliente son accesibles in-game a través de una interfaz rediseñada. Incluye categorías colapsables y barra de búsqueda en tiempo real.
[/ES]

[EN]
LethalWeaponry is a mod for Minecraft Forge 1.12.2 that adds four types of specialized weapons, each with combat mechanics, active skills, and an exclusive forge station.

### 1. Lethal Forge

The mod's weapons are not crafted in a standard crafting table. They must be forged in the **Lethal Forge**.

**Forge Recipe:**

![Lethal Forge Crafting](/img/lethalforge-crafting.png)

**Usage:**
The interface allows selecting the weapon (WarHammer, Katana, Scythe, Chain Blade) and the material (Wood, Stone, Iron, Gold, Diamond). It requires sticks and string depending on the weapon. Full recipes can be viewed using **Just Enough Items (JEI)**.

### 2. Interfaces (HUD & Configuration)

#### HUD Editor
The mod features on-screen indicators for skill cooldowns, blood pacts, and dual-wielding.
To reposition the interface, enter a world, press the configured key, or use the Mod Options menu to access the **HUD Editor**. Here you can drag, drop, and adjust each visual panel. Holding **Shift** temporarily shows all hidden elements to make them easier to reposition.

#### Configuration Menu
All server logic behavior and client preferences are accessible in-game through a redesigned interface. It includes collapsible categories and a real-time search bar.
[/EN]
