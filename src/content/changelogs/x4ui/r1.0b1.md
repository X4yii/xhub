# X4UI r1.0b1

[ES]
## Resumen de Cambios
El primer lanzamiento público del framework X4UI, extraído de Hammers Unbound para proveer una base robusta y moderna para el diseño de interfaces en Minecraft 1.12.2.

### Características
- **Arquitectura DOM de Componentes:** Introducido un árbol de componentes totalmente orientado a objetos (`GuiComponent`) con relaciones padre-hijo, imitando la estructura DOM web.
- **Layouts FlexBox:** Añadido `GuiPanel` con `FlexDirection` (Absolute, Vertical, Horizontal) para posicionamiento y espaciado automático de componentes.
- **Paneles de Scroll y Recorte:** Implementado `GuiScrollPanel` con soporte nativo de OpenGL `GL_SCISSOR_TEST` para enmascarar de forma segura la renderización fuera de los límites.
- **Analizador Nativo de Markdown:** Añadido `GuiMarkdown`, un componente especializado que lee cadenas de markdown puro y las renderiza en nodos de UI interactivos (Soporta encabezados, negrita, cursiva, enlaces, citas, viñetas e imágenes web/locales).
- **Elementos Interactivos:** Incluidas implementaciones listas para usar de `GuiButton`, `GuiToggle`, `GuiSlider` y `GuiLabel`.
- **Propagación de Eventos:** Sistema avanzado para clics, pulsaciones de teclas y desplazamientos de ratón. Los eventos respetan el índice Z, asegurando que los componentes superpuestos se comporten de forma natural.

### Rendimiento y Optimizaciones
- **Renderizado por Bandera (Dirty Flag):** Implementado un gestor robusto de estado `needsLayout`. El motor UI ahora solo recalcula posiciones y tamaños cuando es matemáticamente necesario, reduciendo drásticamente la sobrecarga de CPU en pantallas complejas.
- **Análisis Regex Estático:** `GuiMarkdown` compila sus expresiones de análisis de texto estáticamente al cargar, reduciendo fuertemente los picos de RAM y CPU al abrir manuales o guías.
- **Correcciones de Memoria en Scroll:** Eliminados los tirones del recolector de basura al calcular el factor de escala `ScaledResolution` una sola vez por redimensionamiento de ventana, en lugar de cientos de veces por segundo.

### Corrección de Errores
- Solucionado un problema donde el desplazamiento de la rueda del ratón no respetaba las coordenadas reales en pantalla del puntero, permitiendo ahora un desplazamiento preciso a través de múltiples paneles activos.

## Changelog Summary
The first public release of the X4UI Framework, extracted from Hammers Unbound to provide a robust foundation for modern Minecraft 1.12.2 interfaces.

### Features
- **Component DOM Architecture:** Introduced a fully object-oriented component tree (`GuiComponent`) with parent-child relationships, mimicking web DOM structures.
- **FlexBox Layouts:** Added `GuiPanel` with `FlexDirection` (Absolute, Vertical, Horizontal) for automatic component positioning and spacing.
- **Scroll Panels & Clipping:** Implemented `GuiScrollPanel` with native OpenGL `GL_SCISSOR_TEST` support to safely mask out-of-bounds rendering.
- **Native Markdown Parser:** Added `GuiMarkdown`, a specialized component that reads raw markdown strings and renders them into interactive UI nodes (Supports headings, bold, italics, links, blockquotes, bullets, and web/local images).
- **Interactive Elements:** Included ready-to-use implementations of `GuiButton`, `GuiToggle`, `GuiSlider`, and `GuiLabel`.
- **Event Bubbling:** Advanced event propagation for clicks, keystrokes, and mouse scrolls. Events bubble down the Z-index correctly, ensuring overlapping components behave naturally.

### Performance & Optimizations
- **Dirty Flag Rendering:** Implemented a robust `needsLayout` state manager. The UI engine will now only recalculate positions and sizes when mathematically necessary, drastically reducing CPU overhead on complex screens (like manuals or heavily populated lists).
- **Static Regex Parsing:** `GuiMarkdown` compiles its text-parsing expressions statically on load, heavily reducing RAM and CPU spikes when opening books or guides.
- **Scroll Memory Fixes:** Eliminated garbage collector stuttering by calculating the `ScaledResolution` scaling factor once per window resize, rather than hundreds of times per second during frame renders.

### Bug Fixes
- Fixed an issue where the mouse wheel scroll event did not respect the pointer's actual screen coordinates, allowing targeted scrolling across multiple active panels.
