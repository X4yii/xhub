# X4UI r1.0b6

[ES]
### Compatibilidad Dual Oficial (Forge 1.12.2 + CleanroomMC)
- **Soporte oficial Java 8 (Forge 1.12.2 + LWJGL 2) y Java 25 (CleanroomMC + LWJGL 3):** `PlatformBridge` implementado como **Multi-Release JAR** (`META-INF/versions/21/`) para usar `Cleaner` y virtual threads en JVMs modernas con fallback seguro en Java 8.
- **Abstracciones de Entrada y Gráficos:**
  - `KeyCodes` desacopla constantes de teclado de `org.lwjgl.input.Keyboard`.
  - `UIInput` normaliza deltas de rueda del mouse (LWJGL 2 `±120` y LWJGL 3/GLFW) y protege coordenadas del mouse ante `displayWidth == 0` / `displayHeight == 0`.
  - `IGraphics` incorpora `clearDepthBuffer()` y carga de texturas BGRA sin llamadas directas a `GL11`/`GL12` en componentes.

### Framework Flexible Servidor ↔ Cliente (Con o Sin `Container`)
- **Nuevo `UINetwork` + `ScreenRegistry` + `PacketHandshake`:** Registro y apertura remota de pantallas desde servidor (`openScreen`), cierre remoto (`closeScreen`), toasts (`sendToast`), handshake automático y modo server-optional (`isServerSupported()`, `hasClient(player)`).
- **RPC Request–Response (`PacketGuiRpc` + `RpcResult`):** Consultas asíncronas cliente → servidor desde `GuiBaseScreen`/`GuiBaseContainer` con `request(...)`, timeout configurable, cancelación automática al cerrar la pantalla y `NO_SERVER_SUPPORT` en servidores sin `x4ui`.
- **Estado por Pantalla y Lotes (`UIStateBus.Scope.SCREEN` + `PacketStateBatch`):** `syncedState(key, valor)` se limpia automáticamente en `onGuiClosed()`; `UIStateBus.scopedKey(ns, key)` y `clearNamespace(ns)` evitan colisiones.
- **Canales Multi-Jugador (`UIChannels` + `ClientSessionTracker`):** Suscripción automática por canal (`openChannelScreen`), `broadcastState`, `broadcastBatch` y `broadcastToast` con desuscripción al cerrar pantalla o desconectarse.
- **Seguridad en Red (`ActionGuard` + Rate-Limiting):** Guardas componibles (`opLevel`, `withinDistance`, `withinEntityDistance`, `require`) y cooldown por jugador/acción (`50ms` por defecto).

### Diseño Minimalista y Motor de Layout
- **Tema sólido minimalista por defecto:** Paleta oscura limpia en `DefaultTheme` y variantes de `GuiButton`.
- **Primitivas de `GuiPanel` y `FlexAlign`:** `GuiPanel.row`, `GuiPanel.column`, `GuiPanel.card`, `GuiPanel.spacer()`, `FlexAlign` (`START`, `CENTER`, `END`, `STRETCH`), `createCenteredWindow` y `GuiScrollPanel.vertical`.
- **Correcciones de Layout:** Fix de `percentWidth` respecto a padding y reserva automática de barra en `GuiScrollPanel`.

### Multimedia, Seguridad y Limpieza
- **FFmpeg en el OS del usuario (`MediaManager`):** Descubrimiento automático de `ffmpeg` en Linux, macOS y Windows 10/11 (en lugar de descargarlo en `.minecraft/`), con fallback automático a JCodec cuando no está disponible.
- **Manejo de errores en `GuiVideo`:** Estado de error visible con diagnóstico, barra de estado, limpieza segura de recursos y recuperación ante fallos de red o códec.
- **Seguridad y Sincronización:** `SecurityUtils` para validación SSRF y path traversal; `StateContainerListener` atómico de 32-bit; migración de logs a Log4j2; eliminación total de shims `@Deprecated`.
[/ES]

[EN]
### Official Dual Runtime Support (Forge 1.12.2 + CleanroomMC)
- **Official Java 8 (Forge 1.12.2 + LWJGL 2) & Java 25 (CleanroomMC + LWJGL 3) support:** `PlatformBridge` implemented as a **Multi-Release JAR** (`META-INF/versions/21/`) using `Cleaner` and virtual threads on modern JVMs with safe Java 8 fallbacks.
- **Input & Graphics Abstractions:**
  - `KeyCodes` decouples key constants from `org.lwjgl.input.Keyboard`.
  - `UIInput` normalizes mouse wheel deltas (LWJGL 2 `±120` and LWJGL 3/GLFW) and guards mouse coordinates against `displayWidth == 0` / `displayHeight == 0`.
  - `IGraphics` adds `clearDepthBuffer()` and BGRA texture upload without direct `GL11`/`GL12` calls in components.

### Flexible Server ↔ Client Framework (With or Without `Container`)
- **New `UINetwork` + `ScreenRegistry` + `PacketHandshake`:** Remote screen registration and opening (`openScreen`), remote closing (`closeScreen`), toast notifications (`sendToast`), automatic handshake, and server-optional mode (`isServerSupported()`, `hasClient(player)`).
- **Request–Response RPC (`PacketGuiRpc` + `RpcResult`):** Asynchronous client → server queries from `GuiBaseScreen`/`GuiBaseContainer` via `request(...)` with configurable timeout, automatic cancellation on screen close, and `NO_SERVER_SUPPORT` on vanilla/client-only servers.
- **Screen-Scoped State & Batching (`UIStateBus.Scope.SCREEN` + `PacketStateBatch`):** `syncedState(key, initialValue)` is automatically cleared in `onGuiClosed()`; `UIStateBus.scopedKey(ns, key)` and `clearNamespace(ns)` prevent key collisions.
- **Multi-Player Channels (`UIChannels` + `ClientSessionTracker`):** Automatic channel subscription (`openChannelScreen`), `broadcastState`, `broadcastBatch`, and `broadcastToast` with cleanup on screen close or disconnect.
- **Network Security (`ActionGuard` + Rate-Limiting):** Composable guards (`opLevel`, `withinDistance`, `withinEntityDistance`, `require`) and per-player/action cooldown (`50ms` default).

### Minimalist Design & Layout Engine
- **Solid minimalist default theme:** Clean dark palette in `DefaultTheme` and `GuiButton` variants.
- **`GuiPanel` & `FlexAlign` primitives:** `GuiPanel.row`, `GuiPanel.column`, `GuiPanel.card`, `GuiPanel.spacer()`, `FlexAlign` (`START`, `CENTER`, `END`, `STRETCH`), `createCenteredWindow`, and `GuiScrollPanel.vertical`.
- **Layout fixes:** Fixed `percentWidth` box-model padding calculation and automatic scrollbar width reservation in `GuiScrollPanel`.

### Media, Security & Cleanup
- **OS-level FFmpeg discovery (`MediaManager`):** Automatically locates `ffmpeg` on Linux, macOS, and Windows 10/11 (instead of bundling inside `.minecraft/`), with automatic fallback to JCodec when unavailable.
- **`GuiVideo` error handling:** Visible error state with diagnostics, status bar, safe resource cleanup, and graceful recovery on network or codec failures.
- **Security & Sync:** `SecurityUtils` for SSRF and path traversal protection; atomic 32-bit `StateContainerListener`; Log4j2 logger migration; complete removal of `@Deprecated` shims.
[/EN]
