# `AutomaStaff` y `Comida con alas`

## `AutomaStaff`
Herramienta principal de control rápido. Al sostenerla en la mano principal muestra un **HUD lateral** con 4 modos seleccionables mediante **`Shift + Rueda del ratón`**:

| Modo | Acción sobre Bloque (Clic Izq.) | Acción sobre Autómata (Clic Izq.) |
| :--- | :--- | :--- |
| **`Select Zone`** | Fija `Pos1` (normal) o `Pos2` (`Shift`) | Vincula el bastón y aplica `Pos1`–`Pos2` si ambos están marcados |
| **`Assign Chest`** | Selecciona el cofre objetivo | Vincula el autómata y asigna el cofre seleccionado como depósito |
| **`Whip`** | — | Aplica un empujón suave anti-atasco con partículas y sonido |
| **`Follow / Stay`** | — | Alterna entre `Follow Owner` (seguir) y `Stay Put` (mantener posición) |

### Acciones adicionales con `AutomaStaff`
- **Clic derecho sobre bloque:** Fija `Pos1` (normal) o `Pos2` (`Shift`). Las cajas `Pos1`–`Pos2` se renderizan en el mundo de forma independiente por autómata.
- **Clic derecho sobre autómata (hasta 10 bloques):** Abre su interfaz **X4UI**.

## `Comida con alas` (`Winged Food`)
Espada especializada para combate y gestión segura de autómatas.

| Atributo | Valor |
| :--- | :--- |
| **Daño de ataque** | `9` |
| **Velocidad de ataque** | `1.6` |
| **Durabilidad** | `3200` |
| **Efectos al golpear mobs** | **Náuseas II** (`5 s`) + **Lentitud I** (`5 s`) |

- **Despido de autómatas:** Al golpear con `Comida con alas` a un autómata propio (o a cualquiera con permiso OP), lo despide/elimina de forma limpia y segura.
- **Receta:** Lingotes de oro (`ingotGold`), plumas (`minecraft:feather`), chuleta de cerdo cocida (`minecraft:cooked_porkchop`) y hueso (`minecraft:bone`).

# `AutomaStaff` & `Comida con alas`

## `AutomaStaff`
Primary quick-control wand. Holding it in the main hand displays a **side HUD** with 4 modes cycled via **`Sneak + Mouse Wheel`**:

| Mode | Block Action (Left-Click) | Automaton Action (Left-Click) |
| :--- | :--- | :--- |
| **`Select Zone`** | Sets `Pos1` (normal) or `Pos2` (`Sneak`) | Binds staff and applies `Pos1`–`Pos2` if both are set |
| **`Assign Chest`** | Selects target chest | Binds automaton and assigns the selected chest as deposit target |
| **`Whip`** | — | Applies a gentle unstick nudge with particles and sound |
| **`Follow / Stay`** | — | Toggles between `Follow Owner` and `Stay Put` |

### Additional `AutomaStaff` Controls
- **Right-Click block:** Sets `Pos1` (normal) or `Pos2` (`Sneak`). `Pos1`–`Pos2` boxes render in-world independently per automaton.
- **Right-Click automaton (up to 10 blocks):** Opens its **X4UI** control panel.

---

## `Comida con alas` (`Winged Food`)
Specialized sword for combat and safe automaton dismissal.

| Stat | Value |
| :--- | :--- |
| **Attack Damage** | `9` |
| **Attack Speed** | `1.6` |
| **Durability** | `3200` |
| **On-Hit Effects (Mobs)** | **Nausea II** (`5 s`) + **Slowness I** (`5 s`) |

- **Automaton Dismissal:** Hitting an owned automaton (or any automaton with OP) with `Comida con alas` safely dismisses/terminates it.
- **Recipe:** Gold Ingots (`ingotGold`), Feathers (`minecraft:feather`), Cooked Porkchop (`minecraft:cooked_porkchop`), and Bone (`minecraft:bone`).
[/EN]
